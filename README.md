## Koyeb Deployment

Deploy directly via the **[Koyeb button](https://app.koyeb.com/deploy?type=git&repository=github.com/LilGabrielDev/Spider-Man&branch=main&name=spider-man-md&ports=3000;http;/&env[MODE]=private&env[TZ]=Africa/Nairobi&env[OWNER_NAME]=Spider%20Man&env[BOT_NAME]=Spider%20Man&env[ADMIN_PROTECTION]=on&env[AUTO_READ]=off&env[SESSION_ID]=)** or `koyeb.yaml`:

- **Builder:** Buildpack (`npm start`) or `Dockerfile`
- **Port & Health Check:** Port `3000` (or Koyeb's injected `PORT`) with HTTP check on `/`
- **Secret:** Set `SESSION_ID` or `SESSION` before deploying

## ⚡ Features

- **Multi-Device Auth (Pair Code & QR)** — Supports `SESSION_ID` (`LIL~` gzipped/base64) and `SESSION` (base64 `creds.json`) via `@whiskeysockets/baileys`.
- **AI & Vision Commands** — Built-in GPT, Gemini, DeepSeek, and image vision analysis right inside WhatsApp chats.
- **Media & Social Downloaders** — Download music, playlists, lyrics, audio recognition (Shazam), and videos from YouTube, TikTok, Instagram, Facebook, and X/Twitter.
- **Group Protection & Moderation** — Anti-link, anti-spam, anti-flood, anti-scam, anti-advertisement, 24h anti-duplicate, anti-bot, anti-badword, admin protection, activity stats, reminders, and lockdown mode.
- **WhatsApp Automations** — Anti-delete, anti-edit, anti-call, auto-read, auto-react, status auto-view/like, auto-bio, and view-once media auto-save.
- **Stickers, Converters & Modular Plugins** — Sticker maker, media-to-URL uploader, logo generator, multi-language translator, ZIP backup, native `Spider/commands/` plugins, and full legacy command compatibility.
- **Cloud-Ready Health Server** — Built-in Express server exposing `GET /` and `GET /health`, tuned for Heroku, Koyeb, Render, Railway, Docker, Katabump, Pterodactyl panels, VPS, and Termux.

## 🛠️ Local & Docker

```bash
# Local / VPS / Termux
git clone https://github.com/LilGabrielDev/Spider-Man.git && cd Spider-Man
npm install && cp .env.example .env && npm start

# Docker
docker build -t spider-man-md .
docker run -d -p 3000:3000 -e SESSION_ID="your_session" spider-man-md
```

## ⚙️ Core Environment Variables

| Variable | Description | Default |
| --- | --- | --- |
| `SESSION_ID` / `SESSION` | WhatsApp multi-device session string | *(required)* |
| `MODE` | Bot access mode (`private` / `public`) | `private` |
| `PREFIXES` | Command prefixes (comma-separated) | `.` |
| `OWNER_NAME` / `BOT_NAME` | Owner & bot display names | `Spider Man` |
| `TZ` | Timezone | `Africa/Nairobi` |
| `ADMIN_PROTECTION` | Protect group admins from destructive actions | `on` |
| `PORT` | HTTP server port *(leave unset on managed hosts)* | `3000` |

See `.env.example` and `app.json` for optional API keys and automation toggles.
